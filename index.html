Shaders

Fragment shaders written for projection and live visuals. Each one comes as three files — one for TouchDesigner, one for Resolume and anything else that reads ISF, and one for a web page. Free to use, credit welcome and not required.

Written in the Shadertoy dialect and converted by tools/port.mjs in the repository, so every version of a shader comes from one source. Originals on Shadertoy.
